# CHROMOSOME COSMETICS — אתר יוקרה (Hebrew / RTL)

אתר תדמית ומכירה יוקרתי למותג **Chromosome Cosmetics**, בעברית מלאה (RTL),
בסגנון *Molecular Luxe*: רקע כהה, זהב שמפניה, ירוק ביו־לומינסנטי, אובייקטים
תלת־ממדיים מרחפים, אנימציית DNA וחשיפה בגלילה.

## הרצה מקומית
זהו אתר סטטי — אין שלב build. פשוט פותחים שרת מקומי:

```bash
python3 -m http.server 8000
# ואז נכנסים לכתובת http://localhost:8000
```

או להעלות ל-Netlify / Vercel / GitHub Pages כמו שהוא.

## מבנה
```
index.html          — כל המבנה (עברית, RTL)
styles/main.css     — כל העיצוב, הצבעים והאנימציות
scripts/main.js     — אינטראקציות, נתוני מוצרים, קנבס ה-DNA
assets/logo.svg     — לוגו (זמני — ראו למטה)
assets/product-*.svg — תמונות מוצר (זמניות — ראו למטה)
```

## עריכת מוצרים
עריכת המוצרים (שם, תיאור, מחיר, תמונה) נעשית במקום אחד:
`scripts/main.js` → המערך `PRODUCTS` בראש הקובץ.

---

## ⚠️ מה שאני צריך ממך כדי לסיים "אמיתי"
לא הצלחתי לגשת לאתר הקיים `chromosomecosmetics.com` — הוא חסום ברשת של
סביבת העבודה שלי, אז **הלוגו והמוצרים כרגע הם ממלאי מקום** שעיצבתי בעצמי.
כדי להחליף אותם בתוכן האמיתי, שלח/י לי:

1. **קובץ הלוגו** (SVG/PNG שקוף עדיף) → יחליף את `assets/logo.svg`.
2. **תמונות המוצרים** האמיתיות → יחליפו את `assets/product-1..6.svg`.
3. **רשימת המוצרים** האמיתית: שם + תיאור קצר + מחיר לכל מוצר.
4. טקסטים אמיתיים ל"אודות"/סיפור המותג, אם יש.
5. קישורי רשתות חברתיות אמיתיים (אינסטגרם כבר מקושר — עדכן/י אם צריך).
6. פרטי צבע מותג רשמיים (אם יש), כדי לכוון במדויק את `--gold` / `--emerald`
   ב-`styles/main.css`.

עם החומרים האלה אעדכן הכל לתוכן המדויק של המותג.
