# CHROMOSOME COSMETICS — אתר יוקרה (Hebrew / RTL)

אתר תדמית ומכירה יוקרתי למותג **Chromosome Cosmetics**, בעברית מלאה (RTL),
בסגנון *Molecular Luxe*: רקע כהה, זהב שמפניה, ירוק ביו־לומינסנטי, אובייקטים
תלת־ממדיים מרחפים, אנימציית DNA וחשיפה בגלילה.

## הרצה מקומית
זהו אתר סטטי — אין שלב build. פשוט פותחים שרת מקומי:

```bash
python3 -m http.server 8000
# ואז נכנסים לכתובת http://localhost:8000
```

או להעלות ל-Netlify / Vercel / GitHub Pages כמו שהוא.

## מבנה
```
index.html          — כל המבנה (עברית, RTL)
styles/main.css     — כל העיצוב, הצבעים והאנימציות
scripts/main.js     — אינטראקציות, נתוני מוצרים, קנבס ה-DNA
assets/logo.svg     — לוגו (זמני — ראו למטה)
assets/product-*.svg — תמונות מוצר (זמניות — ראו למטה)
```

## מוצרים — נתונים אמיתיים ✅
המוצרים נשאבו מ-Shopify של המותג (`products.json`): 8 מוצרים בודדים עם
**שמות, תיאורים, מחירים ותמונות אמיתיים**. הכל מוגדר במקום אחד:
`scripts/main.js` → המערך `PRODUCTS` בראש הקובץ.

- התמונות מגיעות ישירות מ-Shopify CDN (כתובות ציבוריות) — נטענות באתר החי.
- אם תמונה נכשלת, מוצג איור מקומי (`assets/product-*.svg`) כגיבוי.

## ⚠️ מה שעדיין חסר / כדאי לאמת
1. **הלוגו** — עדיין ממלא־מקום שעיצבתי (`assets/logo.svg`). שלח/י את הלוגו
   האמיתי (SVG/PNG שקוף) ואחליף.
2. **החבילות (Packages 001–007)** — קיימות בחנות אך עוד לא הוספתי להן סקשן
   ייעודי. אפשר להוסיף "ערכות מתנה" בקלות — תגיד/י אם רוצה.
3. **טקסט "אודות"/סיפור המותג** האמיתי, אם יש.
4. **קישורי רשתות** — אינסטגרם מקושר; עדכן/י פייסבוק/טיקטוק אם צריך.
5. **אימות ניסוחים שיווקיים** — הימנעתי מטענות לא מאומתות (Vegan / "ללא
   ניסוי בבע״ח" / "תוצרת ישראל"). אם הן נכונות ורוצה להחזיר — אפשר.
6. **צבעי מותג רשמיים** לכיול מדויק של `--gold` / `--emerald` ב-CSS.
